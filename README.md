## Quick Start

To open the options window, type `/profiles` or `/upm` into your chat and hit enter.

## Description

Sick and tired of having to go through a million different addon options UIs, just to set up your profiles? Then have I get news for you!<br/>
<br/>
Introducing, Unified Profile Manager! An industry leading addon, designed with all the latest and greatest in addon design*, will now allow you to configure every single** addon out there, all in 1 sexy*** UI!<br/>
*just don't look at the code 😉<br/>
**as long as the addon uses AceDB<br/>
***your mileage may vary<br/>
<br/>
Simply open the option UI, with /profiles or /upm, to manage all addon profiles in 1 compact list.<br/>

<img src="https://i.ibb.co/fzCfgYyz/UPM1.png">

For each addon/profile, you can also open the profile management UI, for even more fine-tuning<br/>

<img src="https://i.ibb.co/wFNsSPwN/UPM2.png">

Besides the standard profile management UI, several extra options are added:

- Prune/delete all unused profiles for an addon
- Apply a specific profile to all alts, for a specific addon
- Several filters in the addon specific, and the All Addons view, allow you to show only characters/addons with non-default profile settings.

<img src="https://i.ibb.co/fzCfgYyz/UPM3.png">

## Install
1. [Download the package](https://github.com/NoM0Re/UnifiedProfileManager-WotLK/archive/refs/heads/master.zip).
2. Open the archive, then open folder `UnifiedProfileManager-WotLK-main`, extract the folder to `Interface\AddOns`.
